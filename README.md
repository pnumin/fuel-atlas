# 지역 주유정보 — 메뉴별 페이지 / 오프라인 배포

## 실행

app 폴더 안의 **index.html**을 Chrome 또는 Edge에서 더블클릭하세요. 인터넷이나 로컬 서버가 필요 없습니다.

이제 HTML 한 파일만 복사하면 실행되는 구조가 아닙니다. **app 폴더의 HTML 파일들과 assets 폴더를 함께 유지해야 합니다.** 압축 배포본은 먼저 전체를 압축 해제한 뒤 index.html을 여세요.

## 페이지 구성

- index.html: 메인 / 메뉴 선택
- extract.html: 지역별 주유소·주유가격 CSV 추출
- map.html: 주유소 지도와 일자별 전체 가격 조회
- 지역주유정보.html: 이전 파일명을 위한 작은 메인 이동 안내
- assets/styles.css: 공통 스타일과 디자인
- assets/home.js: 가벼운 메인 화면 동작
- assets/workspace.js, worker-code.js: CSV·지역·조회 처리
- assets/fuel-hero.png: 메인 일러스트
- assets/geo-index.js: 가벼운 지역 목록
- assets/map/: 원본 좌표를 그대로 유지한 분할 지도 파일 15개
- licenses/: 사용한 라이브러리 이용 조건
- file-sizes.json: 생성 파일별 크기와 체크섬

지도 파일은 map.html에서만 불러옵니다. 메인·추출 페이지는 대용량 경계 좌표를 불러오지 않습니다. 지도는 여러 classic JavaScript 파일로 포함하므로 file:// 직접 실행에서도 fetch나 서버가 필요 없습니다.

## GitHub에 올릴 파일

웹페이지 게시에는 **app 안의 세 HTML(index.html, extract.html, map.html), assets, licenses**를 같은 상대 경로로 올리세요. 저장소 루트 또는 GitHub Pages로 지정한 폴더에 index.html이 있어야 합니다.

개발용 node_modules, Windows 실행 파일 release, evidence 검증 자료, 원본 CSV와 원본 GeoJSON은 웹 게시에 필요 없습니다. 생성된 지도 조각은 assets/map 안에 이미 들어 있습니다. assets 폴더 내부 파일명과 위치를 바꾸지 마세요.

GitHub에서 볼 때도 상대 경로를 사용하므로 저장소 이름이 URL에 포함되는 사이트에서 동작합니다. 인터넷 없는 PC에서 사용하려면 사이트의 HTML과 assets 전체를 내려받아 로컬에서 여세요. 온라인 페이지가 오프라인 캐시된다고 가정하지 않습니다.

## 지역별 자료 추출

1. 메인에서 지역별 자료 추출을 선택합니다.
2. 기본정보 CSV(14개 필수 열)와 가격 CSV(11개 필수 열)를 각각 선택하거나 끌어놓습니다.
3. 시도·시군구를 선택합니다. 전체를 고르면 해당 시도 전체를 처리합니다.
4. 미리보기를 확인한 뒤 두 CSV를 각각 저장합니다.

UTF-8 BOM, 쉼표 구분으로 저장합니다. 원본 열·값·가격 0을 보존하며 지역 내 모든 날짜가 포함됩니다. 두 자료는 독립적으로 필터링하므로 연결되지 않은 가격 행도 저장됩니다.

## 지도·전체 일자별 가격 조회

1. 지도·주유가격 조회에서 두 CSV를 입력합니다. 추출한 지역 자료도 사용할 수 있습니다.
2. 시도·시군구·날짜·유종을 선택합니다.
3. 지도나 목록에서 주유소를 선택하면 상세와 전체 날짜의 네 유종 가격표가 표시됩니다.
4. 묶음 표식은 클릭하여 확대하고, 이름 검색·가격순 정렬을 사용할 수 있습니다.
5. 자료 연결 및 미표시 내역에서 미연결·좌표 없음·중복 충돌을 확인합니다.
6. 기본정보 상세에서 이름·주소·상표를 대조하여 수동 연결할 수 있습니다.

0·빈 가격은 가격정보 없음, 날짜 기록이 없으면 선택일 가격 없음으로 표시합니다. 다른 날짜 값으로 대체하지 않습니다. 표시 단위는 원/L이며 원본 제공처의 단위와 일치하는지 확인하세요.

공통 ID가 없는 두 파일을 잘못 결합하지 않도록 지역·이름·주소가 유일하게 일치하는 경우만 자동 연결합니다. 지도에 없는 가격 자료는 목록에서 확인합니다. 지도는 행정동 경계이며 도로·건물·위성영상을 포함하지 않습니다.

## 페이지 간 작업 유지

동일 탭에서 메뉴 버튼으로 이동하면 파일 자료, 지역·날짜·유종과 수동 연결 상태를 현재 탭의 임시 상태로 이어받습니다. 별도 탭에서 직접 페이지를 열거나 브라우저를 닫은 뒤에는 CSV를 다시 선택하세요. 파일은 외부로 전송되지 않습니다.

UTF-8(선택적 BOM), CP949/EUC-KR 자동 감지·수동 선택을 지원합니다. 인코딩 변경 후 파일을 다시 선택하세요. 오류 행은 행 번호와 원인을 보여주고 사용자가 허용한 경우에만 정상 행을 적용합니다.

## Windows 실행 버전

release/FuelAtlas-win32-x64/FuelAtlas.exe를 실행합니다. 다른 PC로 옮길 때는 이 실행 폴더 전체를 복사하세요. Node.js·브라우저·개발환경 설치 없이 실행됩니다. 실행 버전에도 다중 페이지를 반영했습니다.

## 개발

- npm ci: 개발 의존성 설치 (최초 다운로드 시 인터넷 필요)
- npm run build: 작은 HTML과 분할 assets 생성
- npm test: 데이터·이력·페이지 상태·지도 무손실 검증
- npm run qa: 실제 CSV로 오프라인 Chrome 화면 검증
- SHOW_BROWSER=1 npm run qa: 검증 브라우저를 화면에 표시 (Git Bash)
- npm run package: Windows 실행 폴더 갱신
- node scripts/preview.mjs: 선택적인 localhost 미리보기

빌드 시 상위 전국주유소표준데이터/HangJeongDong_ver20261001.geojson을 사용합니다. 실행·게시 시에는 원본 파일이 필요 없습니다. 빌드에서 개별 배포 파일이 20MiB를 넘으면 오류로 처리합니다.

사용자 참조 디자인의 파스텔 배너·카드·상단 메뉴를 유지했습니다. 디자인 규칙은 상위 DESIGN.md, 라이브러리 라이선스는 app/licenses에 있습니다. 데이터의 이용 조건은 원본 제공처의 조건을 따릅니다.
